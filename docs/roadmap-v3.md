## 0. 本次诊断记录（2026-07-18，代码走查 + Playwright 实测截图 + API 复算）

### 问题一：人物条互相倾轧，缩放不缓解，选中仍看不清

机制级根因四条，全部实测钉死（`frontend/src/components/timeline/TimeColumn.vue`）：

1. **车道数是「全史最大同时在世人数」的全局常数，与宽度、年代都无关**（L730-739）。
   过滤后 303 人按生年贪心分道，`laneCount = 97`（L0 focus 档）。人物区宽 = `max(pxA+44, 视口宽×0.30)`（L744-746, `PERSON_RIGHT=0.30`）→ 默认分栏 720px 时**区宽仅 44px，道距 0.45px**；拉宽到 1097px 也只有 144px / 道距 1.47px。而条宽固定 4px、生卒端点 8/10px——**任何宽度下物理上必然压盖**。稀疏年代同样是一坨：750 年实际在世仅 8 人，但他们的车道索引来自全史峰值 97，同时代者落相邻道。
2. **SplitPane 拖拽后布局根本不重算**：`viewW` 只在滚动/缩放/挂载时更新（L346-352 调用点），全组件无 ResizeObserver。实测拖手柄 720→1097px，人物条 left 值逐像素不变；滚一下才重算。**「缩放不缓解」是独立机制 bug**。
3. **区宽被双重钳制**：`PERSON_RIGHT=0.30` 把新增宽度的 70% 让给事件区；`pxA+44` 地板让窄 pane 时人物区钉死 44px。
4. **选中无聚光**：选中只做「一条变红置顶 + 全宽生命带垫底」，其余条不淡出（dim 链路只对事件生效，L921）；且关系连线 x 坐标公式（L1045/1052）是旧百分比布局残留，连线错落到事件卡区（截图实证虚线斜穿卡片区）。

量化（L0 / focus 默认开 / 720px）：渲染人物条 ~300、车道 97、常显名 25、事件卡 65、溢出刻度 184。
L2 编年档完全可读（20 条/9 道/17 卡/1 溢出）——**压盖是 L0/L1 特有**。

### 问题二：事件被收起后，用户看不出在哪、有多少

- 放不下的事件每个只落一枚 **7×2px、opacity 0.5 的刻度**（模板 L83-89，CSS L1353-1368），同 x 叠放，L0 下 184 枚——远看像一根虚线尺。
- **无分桶、无计数、无「放大可见」可供性**；「回列」是逐事件隐式行为（L884-885 注释）。

### 问题三：「古」底图瓦片缺失

实测盘点（`data/geo/atlas_tiles/` 2408 个 / 56MB，14 幅全部 z2-z6 齐 172 个）：

| 缺口 | 实测 |
|---|---|
| **960-1279 大面积空白（最大元凶）** | mp051b 是图集的**「西夏」区域性图幅**，不是全中国北宋图：156/172 个文件 <2KB，内容只在 z6 x=51-52/y=23-24（河套一带）。中原、江南、岭南在「古」底图上是空白纸面。北宋/南宋/辽/金全图未认 |
| **两大整段无图** | -206~350（汉/新/三国/西晋，557 年）与 1280~2026（元/明/清/民国/共和国，747 年）任何年份落兜底幅 mp0302 史前遗址图 |
| **mp0500 年代存疑** | 定难军是五代建制但也可能是宋初图（handoff 原文，需复核） |
| **zoom 7-10 必 404** | 前端 source `maxzoom:10` 但瓦片只到 z6 → 放大必触发退避灰显「瓦片不可达」 |
| 勘察余量 | mp05xx 70 个有效图幅只看了 24 个（认出 2 幅），**46 个未看**；mp03xx 177 个已认 12 个；mp01xx/mp02xx/mp06xx+ 段位未勘探 |

**管线就绪度**：探针认图→两处表各加一行→幂等脚本（96s/2408 个零失败）→后端自动服出，工作流已闭环。缺的不是机制，是认图人力、mp051b/mp0500 复核、z7+ 磁盘预算（z7 +112MB / z8 +415MB，WORKLOG 实测报价）。

## 1. v3.0 主题与完成的定义

**主题：看得清 —— 时间柱可读性 + 古地图补全。**

M10 收版时逐条核对：

- L0 全景下人物区**道距 ≥ 4px 或聚合态可读**；拖 SplitPane 布局**实时**重算（不再需要滚一下）
- 选中人物时非选中条**淡出**，关系连线落在正确的车道几何上
- 事件溢出槽**有计数徽标**，hover 见清单，点击回列放大；用户任何时候知道「哪里有、有多少」
- 960-1279 不再是大面积空白（认出宋/辽/金全图或显式更正区间）；汉、元明清段落有真图或**显式**留兜底
- zoom 7+ 不再 404 退避（补 z7 或收 maxzoom，由 §6 拍板）
- 新增 E2E 钉子锁住以上各条；pytest ≥58 全绿、validate errors=0 基线不动

## 2. 执行模式

沿用 M6 已验证模式：主代理规划/任务书/验收 + 子代理分波施工；每批结束 `vite build` + pytest 触发线 + Playwright 实测（真 Chrome，dev server 手起手停）；分支 `v3/m<N>-*`，验收后合 main。
内容工程（M9 认图）：代理探针拼图出**候选**判定 + 认图依据（图上地名），Rick/主代理复核认定；存疑标 `disputed`，**没把握不注册**——兜底幅不说假话的红线不动。
