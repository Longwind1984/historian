# Exploration v4 状态系统重做稿

> 角色：Product Manager team／状态与边界
> 审计对象：`docs/product-spec-exploration-v4.md`、`App.jsx`、`styles.css`、`design-qa.md`、`qa-iab-weave.png`、`qa-iab-play.png`、`qa-iab-book.png`
> 边界：只定义产品状态、触发、反馈、恢复、数据合同与验收；不修改原型或生产代码。

## 0. 先给结论：上一版“画出了完成态”，没有设计状态系统

上一版已经找到三种桌面空间重心，但所谓 Loading / Empty / Error 只是一个覆盖整个工作台的演示蒙层，不是三个工作模式各自可运行、可降级、可恢复的真实状态。

这不是“缺几张异常态页面”，而是四个基础问题没有想清：

1. **没有唯一的探索生命周期。**
   文档提到“范围确认 → 渐进编织 → 证据复核 → 可探索”，代码却没有保存这个阶段，也没有定义哪些阶段允许进入播放或书籍工作台。

2. **三态没有共享同一个 Exploration。**
   编织态和播放态是“靖难之役”，书籍态切换成《红太阳是怎样升起的》；这不是同一研究对象的三个视角，而是两个完全不同的演示样例。`mode` 切换会卸载子组件，`eventIndex`、`thread`、`paragraph`、`lens`、`place` 等局部状态随之重置，与“切换不丢上下文”的标注相反。

3. **业务状态、系统状态和证据状态混在一起。**
   “生成中”是异步任务状态，“无地点”是数据可表达性，“模型推断”是认识论状态，“版权受限”是能力门禁。它们不能共用一个 `normal/loading/empty/error` 枚举，更不能用一张全屏卡片覆盖。

4. **没有真实恢复动作。**
   当前 Error 的按钮叫“返回正常状态”，本质是评审作弊器。真实产品必须告诉用户哪一步失败、保住了什么、现在能继续做什么，并提供“重试这一来源 / 更换来源 / 继续使用已完成部分 / 返回编辑范围”等有对象的动作。

因此，上一版 `design-qa.md` 的 `final result: passed` 只能代表视觉和少量演示交互可运行，不能代表产品状态验收通过。状态验收应打回。

## 1. 发布会式定义：用户在任何一秒都应该知道三件事

探索不是聊天回答，也不是一次性生成动画。它是一项可持续的研究工作。每一秒，界面都必须回答：

1. **我正在研究什么？**
   Exploration 身份、研究约定、当前主线、当前 Scene / Claim / Passage。

2. **系统现在做到哪一步？**
   范围待确认、骨架生成、证据核对、部分可用、可播放、后台重编织、保存中、离线排队。

3. **我下一步能做什么？**
   确认范围、先看已完成部分、补充材料、处理歧义、重试局部失败、接受或驳回推断、继续播放。

状态不是用于解释技术故障的文案层，而是组织用户控制权的产品骨架。

## 2. 五层状态模型：禁止继续使用一个 `demo` 枚举包办一切

### L1：探索生命周期 `exploration.lifecycle`

描述整个 Exploration 在研究流程中的位置。

| 状态 | 含义 | 全局可见反馈 | 允许的主要动作 |
|---|---|---|---|
| `new` | 尚无研究对象 | 探索首页，两条入口 | 提问、导入书 |
| `brief_draft` | 已表达兴趣，范围尚未确认 | 研究约定卡显示“待确认” | 修改、确认、放弃 |
| `brief_confirmed` | 研究约定形成基线版本 | 显示范围版本与来源计划 | 开始编织 |
| `weaving` | 骨架、实体与证据逐步生成 | 顶部阶段条 + 局部骨架渐进出现 | 取消、先看已完成部分 |
| `partial_ready` | 至少一部分 Scene 可用，仍在补证 | “可先探索 · 仍有 N 项处理中” | 编织、预览播放、审证 |
| `ready` | 当前版本达到可探索门槛 | “已就绪” | 编织、播放、书籍阅读 |
| `reweaving` | 用户改范围或主线，局部重算 | 旧版本保持可见，变更区显示处理中 | 取消变更、继续浏览旧版本 |
| `degraded` | 部分依赖失败但成果仍可用 | 顶部黄色状态条，具体区域局部错误 | 使用已完成部分、局部重试 |
| `blocked` | 权限、版权或必须输入缺失，不能继续某能力 | 具体能力锁定，不遮住可用内容 | 授权、换来源、缩小输出 |
| `save_pending` | 本地变更尚未同步 | “本地已保存 · 等待同步” | 继续工作、手动重试 |
| `archived` | 只读历史版本 | “只读版本” | 复制为新探索、导出 |

硬规则：

- `degraded` 不等于不可用，局部故障不得把整个 Exploration 清空。
- `blocked` 必须带 `blocked_reason` 与 `allowed_actions`，不能只写“无权限”。
- `ready` 不是“所有材料都已确定”，而是达到所选模式的能力门槛；仍可有证据缺口和不确定地点。
- 所有异步变更形成新 `revision`；旧可用 revision 在新版本完成前继续显示。

### L2：模式能力 `capabilities`

描述编织、播放、书籍是否可进入，不描述当前是否选中。

```ts
capabilities: {
  weave: { enabled: true, reason?: null },
  play: {
    enabled: boolean,
    playable_scene_count: number,
    reason?: "no_scene" | "sequence_incomplete" | "evidence_audit_pending"
  },
  book: {
    enabled: boolean,
    book_count: number,
    reason?: "no_book_source" | "book_permission_required"
  }
}
```

模式按钮不应凭演示需要永远可点：

- 编织态始终可进入，因为它是修正问题与结构的主控制台。
- 播放态在至少有 2 个按顺序排列、且没有致命引用审计问题的 Scene 后可进入“预览播放”；达到本轮验收数量后才显示“完整播放”。
- 书籍态在 Corpus 中存在一本可访问书籍时直接进入；没有书时按钮仍可点击，但进入的是“添加来源”门厅，不是假阅读器。

### L3：区域资源状态 `resource.status`

适用于地图、来源、Scene 列表、阅读器、证据集合等区域：

```ts
type ResourceState<T> = {
  status: "idle" | "loading" | "partial" | "ready" | "empty" |
          "stale" | "error" | "blocked";
  data?: T;
  operation?: {
    id: string;
    stage: string;
    progress?: { completed: number; total?: number };
    cancellable: boolean;
  };
  error?: {
    code: string;
    message: string;
    retryable: boolean;
    failed_scope: string[];
  };
  blocked?: {
    reason: "permission" | "copyright" | "login" | "unsupported_format";
    required_action: string;
  };
  last_good_revision?: string;
  updated_at?: string;
}
```

`partial` 与 `stale` 是关键状态：

- `partial`：新结果已经逐块产生，可立即阅读。
- `stale`：用户修改了范围，屏幕仍显示上一版；必须标明“正在按新范围更新”，不能把旧结果伪装为新结果。

### L4：认识论状态 `epistemic.status`

只描述 Claim / Edge / Location / Time 的可相信程度，不控制页面加载：

- `source_statement`
- `multi_source_corroborated`
- `single_source`
- `author_interpretation`
- `model_inference_pending`
- `disputed`
- `evidence_gap`
- `unresolved_identity`
- `unresolved_place`
- `time_approximate`

它们必须绑定来源和判断主体；不能用五个圆点冒充置信度，也不能把“史实已核验”作为无出处的装饰标签。

### L5：用户交互状态 `interaction`

描述用户在当前界面的瞬时控制：

- `active_mode`
- `active_scene_id`
- `active_claim_id`
- `active_passage_id`
- `active_place_ref`
- `playing / paused / buffering / ended`
- `auto_follow / manual_map`
- `dirty_selection`
- `focus_origin`

这层负责跨模式连续性。离开模式时不能销毁。

## 3. 全局探索状态机

```text
new
 ├─ 提问 ───────────────→ brief_draft
 └─ 导入书 ─→ source_ingest ─→ brief_draft

brief_draft
 ├─ 确认 ─→ brief_confirmed
 ├─ 缺必须输入 ─→ 留在 brief_draft
 └─ 权限/版权不允许处理 ─→ blocked

brief_confirmed
 └─ 开始编织 ─→ weaving

weaving
 ├─ 首批 Scene 完成 ─→ partial_ready
 ├─ 全部阶段完成 ─→ ready
 ├─ 局部来源失败 ─→ degraded
 ├─ 用户取消 ─→ partial_ready 或 brief_confirmed
 └─ 致命失败且无成果 ─→ brief_confirmed + operation error

ready / partial_ready / degraded
 ├─ 改范围或主线 ─→ reweaving
 ├─ 打开播放 ─→ play mode
 ├─ 打开来源书 ─→ book mode
 └─ 保存失败 ─→ save_pending（工作不丢）

reweaving
 ├─ 成功 ─→ ready / partial_ready
 ├─ 取消 ─→ 回退 last_good_revision
 └─ 失败 ─→ degraded + 保留 last_good_revision
```

### 全局进入

| 触发 | 首屏反馈 | 恢复动作 | 验收 |
|---|---|---|---|
| 新访客进入 `/explore` | 两个主入口，不显示空工作台 | 提问 / 导入书 | 不出现“还没有可展示的探索”遮罩 |
| 打开已有探索 | 保留壳，内容区骨架加载；显示探索名 | 取消加载返回最近探索 | 2 秒内至少显示身份与上次保存时间 |
| 深链 Scene / Claim | 先恢复 Exploration，再定位对象 | 对象失效时回到最近有效父级 | 不因对象 404 清空整个探索 |
| 网络离线 | 仍打开本地快照，状态改为“离线 · 本地保存” | 网络恢复自动重试；可手动重试 | 编辑不丢；不虚假显示“已同步” |
| 无访问权限 | 展示探索身份和访问原因，不泄露正文 | 请求访问 / 返回探索首页 | 后退可用；无空白页 |

### 全局退出

- 离开 Explore 路由：自动保存本地草案；若同步未完成，显示可见的 `save_pending`，但不阻止路由跳转。
- 关闭有未发送书籍片段的会话：提示“清除本次发送片段 / 保留本地研究包”，不是笼统的未保存警告。
- 切换到另一 Exploration：保留当前 revision；后台任务可继续，但必须在最近探索列表显示进度和取消入口。

## 4. 三态进入、退出与切换合同

### 4.1 编织态

**定位**：这是研究的“编辑台”，负责定义问题、决定材料边界、建立 Scene 和处理缺口；不是聊天主页。

进入规则：

- 新问题：进入 `brief_draft`，主画布先呈现研究约定，不出现伪造的历史地图。
- 已有探索：恢复上次 `active_scene_id` 与 `active_thread_id`。
- 从播放态返回：定位正在播放的 Scene，并展开它的前因、结果与证据。
- 从书籍态返回：定位当前 Passage 产生或支持的 Claim；若未建立结构，只带回摘录草案。

退出规则：

- 切到播放：保留 Scene、主线、地图视野；后台编织可继续。
- 切到书籍：若当前 Claim 有来源书，定位该出处；否则打开来源选择，不切换研究对象。

### 4.2 播放态

**定位**：这是把已建立的研究结构导演成时空叙事的“演示台”；只播放达到门槛的 Scene，不把待核内容伪装成事实动画。

进入规则：

- `playable_scene_count = 0`：显示不可播放原因和“返回编织”动作，不展示空地图。
- `playable_scene_count = 1`：允许“单 Scene 预览”，播放按钮禁用，明确还需更多 Scene。
- `>= 2`：可播放；未完成 Scene 可在场景轨显示“待核”，默认跳过或由用户选择包含。
- 从编织态进入：以当前 Scene 为起点，不强制跳回第一幕。
- 从书籍态进入：若 Passage 已链接 Scene，以其为起点；否则以当前时间范围中最近 Scene 为候选，并要求用户确认。

退出规则：

- 切换模式、拖地图、点证据、浏览来源都会自动暂停；保留 `active_scene_id`、`rate`、`auto_follow`。
- 离开再返回仍停在同一 Scene，不自动续播。

### 4.3 书籍态

**定位**：这是“原文—作者观察—历史结构—地图—外部证据”的可逆研究台，不是另一个独立产品，也不是伪装成微信读书的阅读器皮肤。

进入规则：

- 当前 Exploration 有一本来源书：恢复 `book_id/chapter_id/passage_id`。
- 有多本书：先显示来源抽屉，保留当前 Claim 上下文。
- 没有书：进入添加来源门厅；选择本地文件、粘贴文本或网页来源。
- 从编织 / 播放进入：优先打开当前 Claim / Scene 的出处；无书籍出处时显示“这个节点没有书籍来源”，提供添加来源，不切成另一题材。

退出规则：

- 原文选区、结构节点、地点和时间必须写入共享 selection。
- 进入播放只播放已接受并有出处的 Scene；模型推断未确认时显示待处理，不自动加入。

### 4.4 切换验收

1. 编织选择“燕军南下”与“军事推进”后切播放，当前 Scene 仍是燕军南下。
2. 播放拖图后暂停，切回编织再返回播放，仍处于暂停和手动地图状态。
3. 从某书 Passage 进入编织，当前 Claim、出处和地点保持一致。
4. 在书籍态选择另一探索的书不应自动替换当前 Exploration；必须显式创建或切换探索。
5. 任一模式后台加载不阻止其他已就绪模式使用。

## 5. 全局壳的状态规格

### G01／探索身份与保存

| 状态 | 触发 | 用户可见反馈 | 恢复 / 动作 | 数据与验收 |
|---|---|---|---|---|
| 默认 | 有已恢复 Exploration | 名称、范围摘要、revision、保存状态 | 点开研究约定 | 名称不能随模式硬编码变化 |
| 加载 | 恢复远端或本地快照 | 壳保持可用，名称骨架；不遮全屏 | 取消并返回最近列表 | 先有身份，再有内容 |
| 空 | 没有 Exploration | 探索首页双入口 | 提问 / 导入书 | 不渲染三态工作台 |
| 错误 | 快照损坏或版本迁移失败 | “无法打开这一版本”，显示最后可用 revision | 打开上一版 / 导出诊断 | 不把损坏状态变成“返回正常” |
| 不确定 | 本地与远端 revision 冲突 | 显示两版时间与差异范围 | 保留本地 / 使用远端 / 复制一份 | 不静默覆盖 |
| 权限 | 私有探索不可访问 | 只显示最少身份与授权说明 | 请求访问 / 返回 | 不泄露研究正文 |
| 版权 | 公开成果含不可分享原文 | 顶部提示“可继续私人研究，公开导出受限” | 调整导出范围 | 不阻断私人阅读 |

### G02／后台任务与进度

加载不能只有 spinner。用户需要知道系统在哪一阶段：

```text
范围已确认
来源计划 4 / 6
骨架 8 / 12
出处已定位 17 / 24
关系待确认 3
```

每一阶段都支持：

- 取消当前 operation；
- 展开查看已完成与失败项目；
- 在 `partial_ready` 时先进入工作台；
- 失败后只重试失败 scope。

验收：取消后 1 秒内停止新增结果；已完成节点、引用与用户编辑继续存在。

### G03／权限与版权门禁

权限与版权是两套不同状态：

- **权限**：用户有没有读取本地文件、网页会话、私有探索或外部连接的能力。
- **版权**：已读取内容允许如何处理、保存和分享。

```ts
source_access: {
  permission: "granted" | "prompt" | "denied" | "expired";
  rights: "private_analysis" | "quote_limited" | "share_summary_only" |
          "public_redistribution_allowed" | "unknown";
  provenance: string;
  allowed_operations: string[];
}
```

硬规则：

- “已署名”不是版权状态。
- `rights=unknown` 时仍可允许用户私人本地分析，但默认禁止公开全文、长引文和全文索引导出。
- 门禁必须落在具体动作上：可以阅读、可以结构化、可以短引、可以分享摘要、不可公开原文；不应一刀切锁住整个工作台。

## 6. 编织态区域状态

### W01／研究约定与输入

| 状态 | 触发 | 用户看到什么 | 恢复动作 | 数据合同 / 验收 |
|---|---|---|---|---|
| 默认 | `brief_confirmed` | 约定摘要：问题、时间、空间、对象、主线、排除项 | 编辑某一项 | `brief.revision` 可追溯 |
| 加载 | 正在把自然语言改写为 Brief | 原问题保留；建议项逐块出现 | 取消解析，继续手填 | 不锁 textarea |
| 空 | 尚未输入 | 问题输入与两条示例，不出现地图与史实 | 输入问题 / 导入书 | 这是探索首页后的第一工作态 |
| 错误 | LLM 无响应 | 原问题和手填项保留 | 重试改写 / 手动定义 | 失败不删除输入 |
| 不确定 | 时间、地名或主体歧义 | 歧义字段被点亮，给 2–3 个候选与依据 | 选择、保留模糊范围 | 未解决前可保存，不能伪装已确认 |
| 权限 | 外部来源未授权 | Brief 仍可编辑；来源范围显示不可用 | 授权 / 改用本地知识库 | 不阻止定义问题 |
| 版权 | 指定书不能外传 | 明确私人分析与分享边界 | 接受私人模式 / 换来源 | 范围确认必须记录 rights |

关键纠正：当前截图一进入就显示“范围已确认”，但没有“用户确认”这一动作；流程条也固定前两步 done。正式状态必须由 `brief.status` 驱动。

### W02／主线与骨架

| 状态 | 触发 | 用户看到什么 | 恢复动作 | 数据合同 / 验收 |
|---|---|---|---|---|
| 默认 | 有可用 Thread 与 Scene | 6–12 个骨架；当前主线高亮 | 切主线、展开 Scene | `thread.scene_ids` 稳定排序 |
| 加载 | 首批或局部重编织 | 已完成节点保持可点；待生成位置是轻骨架 | 取消、先看已完成 | 每个节点独立进入 ready |
| 空 | Brief 已确认但尚无 Scene | “还没有形成骨架”及原因 | 开始编织 / 调整范围 | 不展示伪事件 |
| 错误 | 一部分节点生成失败 | 失败节点原位显示，其他节点可用 | 只重试失败节点 | `failed_scope` 精确到 Scene |
| 不确定 | 模型提议关系未确认 | 边用待定样式，显示“模型提议” | 接受 / 驳回 / 改写 | 未确认边不能成为事实播放 |
| 权限 | 某来源不可访问 | 相关节点显示“来源受限” | 换来源 / 移除节点 | 不把不可访问写成证据缺口 |
| 版权 | 来源只能私人分析 | 节点可用；分享标识受限 | 改写为摘要 / 移除长引 | 编辑态不必清空 |
| 证据冲突 | 同一 Claim 有不可兼容材料 | Scene 节点出现冲突徽标，不自动选边 | 打开命题级比较 | 冲突必须绑定双方引用 |

### W03／地图

| 状态 | 触发 | 用户看到什么 | 恢复动作 | 数据合同 / 验收 |
|---|---|---|---|---|
| 默认 | 当前 Scene 有可靠 geometry | 当前地点、历史标签、路线和定位依据 | 点地点 / 路线 | 地图内容与 Scene 同 revision |
| 加载 | 瓦片或 geometry 更新 | 保留上一帧，局部进度提示“正在载入新范围” | 取消自动镜头 | 不用全屏蒙层 |
| 空 | 当前探索还没有任何地点 | 中性底图 + “尚未提取到地点” | 展开含地理材料的 Scene | 空不等于错误 |
| 错误 | 瓦片失败 | 保留地点列表与事件详情，地图区域显示错误 | 重载地图 / 切换底图 | 时间与证据仍可用 |
| 不确定 | 同名地点、模糊范围 | 候选点或范围面，不下精确 pin | 选择候选 / 保留未定位 | `certainty`、`candidates`、`source_ref` 必填 |
| 权限 | 私有图层不可访问 | 公共/本地底图仍可用，私有层锁定 | 授权 / 隐藏图层 | 不封整个地图 |
| 版权 | 某底图不可公开展示 | 私人预览提示；导出使用许可底图或无底图模式 | 切换许可底图 | 地理 overlay 可继续 |
| 无地点 | 当前 Scene 没有可靠地点 | 保留上一有效范围，明确“此 Scene 无可靠地点”；不高亮旧点 | 继续下一 Scene / 查看时间证据 | `geo_resolution=none`；旧地图不得冒充当前定位 |

当前缺口：播放态对“无地点”有一句说明，编织与书籍地图没有真实状态；所有路线一直显示，即便当前事件不支持它们。

### W04／事件详情

| 状态 | 用户反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | What / Why / Before / After + 证据状态 | 查看出处、加入播放 | 每个事实句可定位来源 |
| 加载 | 旧摘要保留，“正在按新主线更新” | 取消更新 | 不清空 |
| 空 | 当前只有结构节点，无摘要 | 生成摘要 / 手动撰写 | 不自动补事实 |
| 错误 | 摘要失败但引用仍显示 | 重试摘要 | 引用不丢 |
| 不确定 | 模型因果建议分区展示 | 接受 / 驳回 | 不写入“当前作用”事实栏 |
| 证据冲突 | 同一 What / Why 有冲突 | 显示冲突命题数 | 打开比较 | 不以“尚无冲突”覆盖真实冲突 |

当前缺口：`当前作用` 永远由字符串拼接成“某主线中的转折点”，并不来自 Claim / Edge；前因后续仅取数组相邻项，不能证明因果。

### W05／证据透镜

| 状态 | 用户反馈 | 恢复 / 动作 | 数据合同 / 验收 |
|---|---|---|---|
| 默认 | 1–3 条最相关材料，展示关系而非星级 | 打开原文、换关系视角 | `claim_id + source_ref + locator` |
| 加载 | 当前证据保留，新增来源逐条出现 | 取消核对 | 不闪空 |
| 空 | “当前 Claim 尚无可定位材料” | 添加来源 / 标待补证 | 不生成占位反方 |
| 错误 | 指明失败来源 | 单源重试 / 换源 | 其他来源可用 |
| 不确定 | 关系分类待确认 | 改为互证/补充/范围限制等 | 必须记录判断者 |
| 权限 | 出处不可访问 | 可显示引用元数据与受限原因 | 请求权限 / 找替代 | 不伪装为不存在 |
| 版权 | 原文不可长引 | 只显示摘要与定位 | 在私人阅读区查看 | 分享时自动收缩 |
| 证据冲突 | 同一 Claim 的命题不可共真 | 显示双方命题、证据、适用范围 | 标记直接冲突 / 限定范围 / 暂不判断 | “无冲突”只在核对已完成后出现 |

## 7. 播放态区域状态

### P01／场景轨

| 状态 | 触发与反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 当前、已看、未看、分支清晰 | 跳转 | 不把“已看”当“已核验” |
| 加载 | 下一 Scene 正在预取，轨道不动 | 继续停留 / 跳到其他已就绪 Scene | 不自动越过当前 |
| 空 | 无可播放 Scene | 说明门槛缺什么 | 返回编织 | 不显示空编号 |
| 错误 | 某 Scene 无法加载 | 原位标错，可跳过 | 重试 / 跳过 | 顺序编号保持稳定 |
| 不确定 | Scene 待核或边界模糊 | 状态徽标；默认暂停确认 | 包含一次 / 排除 / 回编织 | 不自动作为事实播放 |
| 权限/版权 | Scene 引用材料不可用于公开演示 | 私人播放可用或该 Scene 锁定 | 换来源 / 只播摘要 | 能力按场景判定 |
| 证据冲突 | 当前 Scene 存在争议 | 轨道标冲突，不停止全部播放 | 播放到此自动暂停或按用户设置继续 | 用户能在一键内看冲突命题 |

### P02／地图舞台

默认、加载、空、错误、不确定、权限、版权、无地点与 W03 使用同一地图合同，播放态另加：

- `camera_transition` 时播放控制显示“镜头过渡”，Scene 不提前标成已完成。
- 手动拖动立刻 `playing → paused`、`auto_follow → false`，提示“已暂停自动跟随”；提供“回到当前 Scene”。
- `no_location` Scene 保留上一有效地图，但地图浮窗标题应明确“无地图定位”，不能把 `lastPlace` 放在主标题位置造成误解。
- 地图失败时 Scene 仍播放时间、人物和叙事；控制栏显示“无地图播放”。

当前缺口：`lastPlace` 被当作浮窗地点标题展示，虽然小字写“保留上一范围”，仍容易让用户把上一地点理解为当前事件地点。

### P03／解释透镜

| 状态 | 用户反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 当前 Scene 最相关 Claim 与材料关系 | 打开出处 | 不固定两张卡 |
| 加载 | 当前材料保留，显示核对中来源 | 取消 / 继续播放 | 不阻断 Scene |
| 空 | 本 Scene 只有事实顺序，无解释材料 | “本幕暂无解释层” | 添加材料 | 允许留白 |
| 错误 | 指明哪一来源失败 | 重试单源 | 不显示虚假完整 |
| 不确定 | 关系待判定 | 暂停并确认或稍后处理 | 待确认标签持续可见 |
| 权限/版权 | 受限材料仅显示元数据或短摘要 | 原站打开 / 私人阅读 | 公开播放不泄露原文 |
| 证据冲突 | 双方命题、适用范围、来源并列 | 展开比较 | 不能默认红蓝对打；仅真实冲突出现 |

### P04／播放控制

```text
idle → buffering → playing → paused → ended
                  ↘ scene_error → paused
manual_map / evidence_open / mode_exit：playing → paused
```

| 状态 | 控件反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认暂停 | 播放、前后步进可用 | 开始 | 初次进入不自动播放 |
| 缓冲 | 播放键转为进度，显示正在预取哪一幕 | 取消 / 跳到已就绪幕 | 不重复点击触发多个 operation |
| 播放中 | 当前 Scene、地图、浮窗、时间带同 revision | 暂停 | 不出现跨帧错位 |
| 暂停 | 显示暂停原因：用户、拖图、证据、错误 | 继续 / 回到当前 Scene | 原因不是通用“暂停中” |
| 结束 | 显示重播与回到关键 Scene | 重播 / 继续探索 | 再点播放从头开始，不停在末尾 |
| 错误 | 当前 Scene 保留，控制暂停 | 重试 / 跳过 | 不自动结束整个故事 |
| reduced motion | 无飞行动画，直接切换或淡入 | 播放 | 功能不缩水 |

当前缺口：速度 select 没有连接状态，改变 0.5× / 1.5× 不会影响 1500ms 定时器；结束时再点播放不会重头；没有 buffering，也没有暂停原因。

### P05／时间带

| 状态 | 反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 时间范围、当前 Scene、密度/分支 | 点选、缩放 | 与 Scene 时间单一真相 |
| 加载 | 新时间范围以虚线预览，旧范围可用 | 取消重算 | 不跳轴 |
| 空 | Scene 无时间信息 | 显示“时间待定”，不造年份 | 回编织 |
| 错误 | 时间索引失败 | 用场景轨播放 | 重建索引 | 地图和详情不失效 |
| 不确定 | 约年、区间、先后不定 | 区间带/模糊端点 | 用户确认 | 不把约年画成精确点 |
| 证据冲突 | 不同材料给出不同日期 | 同时显示候选日期和来源 | 选择演示基准或保留争议 | 时间冲突不藏在证据栏 |

## 8. 书籍态区域状态

### B01／来源选择与网页兼容

| 状态 | 触发 | 用户可见反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|---|
| 默认 | 内置文本可读 | 来源类型、版本、页码体系、同步能力 | 切来源 | 不伪装网页为已导入文本 |
| 加载 | 本地解析或网页导航 | 显示具体阶段：读取目录/建索引/加载网页 | 取消 | 原有 Passage 保留 |
| 空 | 没有来源 | 添加来源门厅 | 导入 / 粘贴 / 填 URL | 不显示假书 |
| 错误 | 文件损坏、网络失败 | 失败原因和可救回部分 | 换文件 / 重试 / 仅导入可读章节 | 不静默跳过 |
| 不确定 | 版本、作者、页码不一致 | 候选元数据与影响 | 选择版本 / 自定义 | 出处定位不能在未确认时声称精确 |
| 权限 | 本地文件权限撤销、网页需登录 | 保留书籍元数据，正文锁定 | 重新选择文件 / 原站登录 | 不丢已建结构 |
| 版权 | 权利状态未知或分享受限 | “私人分析可继续；公开导出只含摘要/短引” | 接受范围 / 更换来源 | 不把版权写成登录问题 |

当前缺口：网页来源是本地硬编码仿制页面，不是真实 iframe 状态；“兼容预览”只有一句提示，没有载入、需登录、禁止内嵌、网络失败四种产品状态。

### B02／内置阅读器

| 状态 | 用户反馈 | 恢复 / 动作 | 数据合同 / 验收 |
|---|---|---|---|
| 默认 | 章节、版本、页码、阅读进度、当前 Passage | 翻页、目录、选区 | `locator` 可回跳 |
| 加载 | 当前页保持，页边显示解析阶段 | 取消索引 / 继续阅读已解析章 | 长书不锁整本 |
| 空 | 尚未导入或选定章节无文本 | 导入 / 换章节 | 不造原文 |
| 错误 | 文件损坏、章节失败、文本层缺失 | 跳过坏章 / OCR 后置提示 / 换文件 | 失败章节可枚举 |
| 不确定 | 页码映射、版本或 OCR 置信不足 | 页码前标“约”或“扫描页” | 校准页码 | 不声称精确出处 |
| 权限 | 本地句柄失效 | 已提取结构仍可看，原文区锁定 | 重新授权文件 | 不自动上传 |
| 版权 | 仅允许私人使用 | 阅读不受影响；复制、导出受范围限制 | 查看可导出范围 | 原文不进入公开包 |

### B03／段落到结构

| 状态 | 用户反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 原文直述、作者判断、实体与关系明确分层 | 点节点双向定位 | 每个节点有 provenance |
| 加载 | 已确认节点保留，新提取节点逐项出现 | 取消 / 先审已完成 | 不整图闪烁 |
| 空 | 当前 Passage 未提取到结构 | 手动标注 / 换 Passage | 允许“没有结构价值” |
| 错误 | 提取失败 | 重试 Passage / 手动创建 | 原文不丢 |
| 不确定 | 模型推断、实体或关系待确认 | 接受 / 驳回 / 改写 / 合并候选 | 未确认不进入事实层 |
| 权限/版权 | 外部核对不可用或引文受限 | 作者结构仍可用，外部节点受限 | 换源 / 摘要化 | 不锁核心阅读 |
| 无地点 | Passage 有论点但无地点 | 地点列为空并注明“未定位” | 继续结构化 | 不从人物籍贯猜点 |
| 证据冲突 | 原文内部或外部材料与 Claim 冲突 | 冲突边只连同一 Claim | 比较、限定范围 | 不把不同层级当冲突 |

当前缺口：逻辑图节点固定，只有“作者观察”和地点能点击；没有接受、驳回、改写或出处回跳，因而还不是可审结构。

### B04／书籍地图

使用 W03 地图合同，另加书籍语义：

- `passage_places` 只包含当前 Passage 可支持地点；
- `chapter_extent` 是背景，不得以激活样式冒充当前 Passage；
- 事件发生、材料写作地、作者回忆地、人物籍贯必须是不同 `role`；
- 路线只有来源明确的移动才画实线；思想影响、材料流通另用语义；
- 同名地名进入 `unresolved_place`，显示候选，不自动选现代同名点。

状态与动作：

| 状态 | 用户反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 当前 Passage 地点高亮，章节地点弱化 | 点地点反查 Passage | 双向联动 |
| 加载 | 保留章节底图，解析地点逐项出现 | 取消解析 | 不移动到未确认点 |
| 空 | 本段没有地点 | “本段不具备可定位信息” | 看章节范围 / 下一段 | 不画路线 |
| 错误 | 地图资源失败 | 地点文本列表仍可用 | 重载 / 无地图阅读 | 原文、结构不受阻 |
| 不确定 | 同名地点或范围过大 | 候选点/范围 + 来源片段 | 选择 / 暂不定位 | 未确认不进事实地图 |
| 权限/版权 | 私有图层或底图受限 | 切换许可底图；overlay 仍在 | 授权 / 切换 | 私人书不等于地图也私有 |

当前缺口：点击西安、重庆只改变右下角标签，不会反向高亮 Passage / Claim / Evidence；三点与两条路线永远存在，不能证明它们来自当前段落。

### B05／叙述时间

| 状态 | 用户反馈 | 恢复 / 动作 | 验收 |
|---|---|---|---|
| 默认 | 章节范围与当前 Passage 时间分层 | 筛选 Passage | 叙述时间、来源时间、成书时间分开 |
| 加载 | 旧范围保持，新时间候选逐项出现 | 取消 | 不跳轴 |
| 空 | Passage 无时间 | “时间未指明” | 手动标注 / 继续 | 不以章节年份代替 Passage |
| 错误 | 时间解析失败 | 手动输入 / 重试 | 原文仍可读 |
| 不确定 | 约年、回忆、跨期、版本差异 | 模糊区间和类型标签 | 确认 / 保留模糊 | 视觉不伪精确 |
| 证据冲突 | 两个来源日期不同 | 候选日期并列 | 选择展示基准 / 保留冲突 | 冲突可追溯 |

当前缺口：时间按钮只有样式，没有筛选或跨区域联动；第一段 `1941—1942` 因字符串包含年份而同时高亮两个点，但没有表达区间。

### B06／关系化证据

沿用 W05 状态，强调：

- 默认只展示作者视角及最相关关系；“不同解释”不是固定必有 Tab 内容。
- `direct_conflict` 只有在同一 Claim 上存在不可共真的陈述时出现。
- `no_conflict_found` 只有 `conflict_check.status=completed` 后可以显示；核对未完成时应写“尚未完成冲突核对”，不能写“尚无实质冲突”。
- 作者观点不需要五点“置信分”；应显示“作者明确陈述 / 由段落归纳 / 模型推断”。

### B07／隐私、权限与版权

这是常驻可审计状态，不是一枚“私人会话”徽章。

用户点开后必须看到：

```text
原文件：仅本机
章节索引：仅本机
本次发送给模型：第四章第 232–233 页，共 N 字
服务端保存：不保存全文 / 保存摘要（实际策略）
公开导出：事件摘要、短引、出处
不会导出：原文全文、全文索引、私人批注
```

状态：

- `private_local`
- `private_with_remote_fragments`
- `share_summary_only`
- `share_with_selected_quotes`
- `public_redistribution_allowed`
- `cleared`
- `permission_lost`
- `rights_unknown`

验收：清除会话后，远端任务引用和本地文件句柄状态有明确反馈；公开导出预览能逐项列出将带出的内容。

## 9. 证据冲突不是一种页面，而是一条可审计关系

冲突判定流程：

```text
两个材料
  → 是否谈同一个 Claim？
  → 时间、对象、范围是否一致？
  → 两个命题能否同时为真？
      ├─ 能：互证 / 补充 / 层级不同 / 方法差异 / 范围限制
      └─ 不能：direct_conflict
```

数据合同：

```ts
type EvidenceRelation = {
  relation_id: string;
  claim_id: string;
  left: { evidence_id: string; proposition: string; locator: string };
  right: { evidence_id: string; proposition: string; locator: string };
  type:
    | "corroborates"
    | "complements"
    | "different_level"
    | "method_difference"
    | "scope_limitation"
    | "direct_conflict"
    | "unclassified";
  rationale: string;
  decided_by: "model" | "user" | "editor";
  status: "proposed" | "confirmed" | "rejected";
}
```

用户可见反馈：

- `proposed`：虚线标签“关系待确认”；
- `confirmed`：实体标签；
- `rejected`：不再参与叙事，但保留审计记录；
- `direct_conflict`：不替用户裁决，显示双方命题、范围和来源；
- 没有外部材料：显示“尚无外部材料”，不是“无冲突”。

## 10. 原型必须如何重做状态演示

### 10.1 删除“全屏状态切换器”的产品假象

当前顶部 `正常 / Loading / Empty / Error` 只可作为内部调试入口，但下一版调试入口必须至少包含：

```text
模式：编织 / 播放 / 书籍
区域：全局 / W01...W05 / P01...P05 / B01...B07
场景：加载 / 空 / 错误 / 不确定 / 权限 / 版权 / 无地点 / 证据冲突
```

选择状态后只改变目标区域，不应以 `demo-layer` 遮住整个 workspace。

### 10.2 下一版必须可现场演示的 12 条状态故事

1. 新问题 → Brief 解析 → 地名歧义 → 用户确认 → 开始编织。
2. 编织逐块出现 3 个 Scene，取消后保留已完成部分。
3. 一条外部来源失败，右侧局部错误；地图和其他证据仍可用。
4. 改主线触发 reweaving，旧主线保持可读，局部更新后无缝替换。
5. 无可靠地点 Scene：播放继续，地图保留上次范围但不冒充当前地点。
6. 拖地图自动暂停；一键回到当前 Scene 并恢复 auto-follow。
7. Scene 证据冲突：播放到此暂停，解释透镜展示真实命题级冲突。
8. 未导入书时进入书籍态，出现来源门厅，而不是预装样例。
9. 长书解析：目录先可用，章节索引逐步完成，用户可先读。
10. 微信读书需登录 / 禁止内嵌 / 页面可见但选区不可读三种不同状态。
11. 当前 Passage 无地点：逻辑图可用，地图明确留白，不猜点。
12. 私人书公开导出：展示版权边界，自动排除原文与全文索引，只保留允许的摘要、短引和出处。

### 10.3 状态视觉原则

- Loading：优先骨架与保留旧内容，不用居中 spinner 夺走工作。
- Empty：解释为什么为空，并给唯一下一步；不把初次使用写成错误。
- Error：说明失败对象、保留成果和恢复动作；错误贴近对象。
- Uncertain：显示候选、依据和影响；不使用恐吓色。
- Permission：说明需要的权限及用途；允许继续使用不依赖该权限的能力。
- Copyright：说明允许与禁止的操作；私人研究与公开分发分开。
- No location：地图仍是结构位置，但不下点、不画线、不把上一地点作为当前。
- Evidence conflict：命题级、来源级、可审计；不为了版面饱满制造两派。

## 11. 开发级共享数据合同

```ts
type ExplorationSnapshot = {
  id: string;
  revision: string;
  lifecycle:
    | "new" | "brief_draft" | "brief_confirmed" | "weaving"
    | "partial_ready" | "ready" | "reweaving" | "degraded"
    | "blocked" | "save_pending" | "archived";
  title: string;
  brief: {
    status: "draft" | "needs_confirmation" | "confirmed";
    question: string;
    time_range?: TimeRange;
    geo_scope?: GeoScope;
    actors: EntityRef[];
    threads: ThreadRef[];
    exclusions: string[];
    revision: string;
  };
  corpus: SourceRef[];
  threads: Thread[];
  scenes: Scene[];
  claims: Claim[];
  evidence: Evidence[];
  relations: EvidenceRelation[];
  capabilities: Capabilities;
  interaction: {
    active_mode: "weave" | "play" | "book";
    active_thread_id?: string;
    active_scene_id?: string;
    active_claim_id?: string;
    active_passage_id?: string;
    active_place_ref?: string;
    playback: {
      state: "idle" | "buffering" | "playing" | "paused" | "ended";
      rate: number;
      pause_reason?: string;
      auto_follow: boolean;
    };
  };
  operations: Operation[];
  save: {
    local: "saved" | "pending" | "error";
    remote: "saved" | "pending" | "offline" | "conflict" | "error";
    last_saved_at?: string;
  };
}
```

关键原则：

- 只有一个 `active_scene_id`，地图、时间带、浮窗、解释透镜读取同一 selection。
- 三个模式使用同一个 Snapshot，不在组件内部各存一套演示状态。
- Operation 独立存在，用户可取消和局部重试。
- 每个 Source 自带 permission 与 rights，权限/版权不从页面文案猜。
- 地点、时间、关系的不确定性属于对象，不属于页面。

## 12. 状态验收闸门

下一版不能再以“能打开 Loading 蒙层”作为通过。必须满足：

1. 每个状态都有可复现触发，不靠直接改 `demo` 为“正常”结束。
2. 每个错误都能指出失败对象、保留成果、可选恢复动作。
3. 三态切换后 Exploration、Scene、Claim、Passage 和地图上下文不丢。
4. 两个后台 operation 可独立显示、取消和重试，不互相覆盖。
5. 编织部分完成时可先探索；取消/失败不清空已完成节点。
6. 播放无地点 Scene 时不显示上个地点为当前地点。
7. 播放缓冲、暂停原因、结束重播、速度切换都真实生效。
8. 书籍未导入、文件损坏、无文本层、版本页码不一致均有独立状态。
9. 网页需登录、禁止内嵌、网络失败、页面可见但选区不可读可分别演示。
10. 权限门禁不冒充版权判断；版权限制不阻断被允许的私人分析。
11. “尚无实质冲突”只在冲突核对完成后出现；无材料时显示证据缺口。
12. 无地点、模糊时间、同名实体、模型推断都不伪装成精确事实。
13. 地图、时间、人物、浮窗、证据同帧读取同一 revision。
14. 状态演示发生在目标区域，其他区域保持可操作；只有致命探索载入失败才允许全页错误。
15. 公开导出前可以预览将包含/排除的书籍材料，且默认不含全文、全文索引和私人批注。

## 13. 对现有原型的逐条定性

### 只是 demo overlay

- 顶部 `正常 / Loading / Empty / Error` 选择器。
- `DemoLayer` 的三张全屏卡片。
- “返回正常状态”按钮。
- 所有模式共享的“正在编织研究网络”Loading 文案。
- QA 所称 “Empty、Error 与同一状态合同实现”，实际只证明蒙层能显示。

### 有视觉表达，但产品合同未落地

- 流程条固定显示前两步完成，不受生命周期驱动。
- “范围已确认”“自动保存”“已导入”“史实已核验”都是静态标签。
- 编织事件状态有三种文案，但没有对应交互、来源或恢复。
- 播放无地点有提示，但以 `lastPlace` 作为主地点，语义仍有误导。
- 书籍网页兼容态有边界文案，但没有真实网页加载、登录和嵌入失败状态。
- 私密徽章只表态，没有展示发送片段、保存策略和导出边界。
- “尚无实质冲突”固定出现，没有冲突检查完成度。

### 完全没想清

- Exploration 在三态之间到底是不是同一个对象。
- 修改研究范围后，旧结果如何保留、哪些区域变 stale、如何局部替换。
- 播放门槛、待核 Scene 是否播放、冲突 Scene 是否自动暂停。
- 书籍态没有来源时是什么，不同书如何进入同一探索。
- 操作取消、局部失败、离线保存、revision 冲突与恢复。
- 权限和版权分别阻止什么动作。
- 证据分数的含义；五个圆点没有可审计定义。
- 人物状态在播放态并未出现，虽然规格把它列为核心联动。
- 时间按钮、地图点、逻辑节点和证据卡多数只改变样式或硬编码文案，没有形成双向数据链。

## 最终判断

三种空间布局可以保留为下一版视觉基础，但状态系统必须从“全屏演示层”改成“一个共享 Exploration + 分层状态 + 区域降级 + 可恢复 operation”。在完成上述 12 条现场故事与 15 条状态验收前，不应再把原型标记为开发就绪。
