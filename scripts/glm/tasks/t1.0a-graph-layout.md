# 任务：修复谱系星图布局塌缩（P0）

## 目标
打开「谱系星图」路由后，用户能立即看到关系图画布（Cytoscape 渲染的节点和边）。
当前症状（2026-07-11 浏览器实测）：路由切换成功、`GET /api/links/global?limit=120&min_links=2` 正常返回（120 节点/284 边）、Cytoscape canvas 已创建——但图区高度塌缩成一条约 40px 的细带：顶部工具条（邻居/路径/全局 模式按钮）、截断警告条（"…过多,只显示前 200/283 个(按类型优先级排序)"）、FilterWhere 筛选控件、⊕ 按钮全部相互叠压，画布完全不可见。实体详情面板（EntityDetail）展开时占据几乎全部可视高度，画布被挤出。

## 已知诊断线索
- `frontend/src/views/GraphView.vue`：`.gv-body { flex:1; min-height:0; position:relative }`，其中 `:deep(.graph-detail) { max-height: 50% }` 试图约束详情面板——检查该选择器是否真的命中 EntityDetail 的根元素类名。
- `frontend/src/components/graph/GraphPanel.vue`（约 586 行）：内部为 工具条 + 画布容器 + EntityDetail 组合。重点排查：画布容器是否缺 `flex:1`/`min-height` 约束；工具条与警告条是否绝对定位导致叠压；cytoscape 容器初始化时高度是否为 0（cytoscape 在 0 高容器里 mount 后不会自动恢复，修复布局后可能需要 `cy.resize()`）。
- `frontend/src/components/graph/EntityDetail.vue`（约 709 行）：根元素类名与滚动约束。
