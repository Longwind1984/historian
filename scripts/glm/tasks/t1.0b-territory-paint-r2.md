但首绘触发选了 `map.once('style.load', ...)`——实测失败：

**浏览器实测证据（2026-07-11）**：整页刷新后，`/api/territories` 请求一次都没有发出（网络面板为空），图例仍显示「无疆域数据」。
即 `style.load` 回调从未执行。原因：Map 构造时传的是**内联 style 对象**（`buildStyle()` 返回的 JSON，无需网络请求），style 解析在构造过程中同步/微任务内完成，`style.load` 事件在 `onMounted` 里 `once()` 挂上之前就已经发过了；错过即永远不再来。

## 本轮要求：把首绘触发改成不赌事件时序的确定性逻辑
在 map 创建后立即执行（伪代码，含义必须完整保留）：
```js
let painted = false
const tryFirstPaint = () => {
  if (painted) return
  painted = true
  map.off('styledata', tryFirstPaint)
  paintTerritories(store.year)   // 内部已有 try/catch + styledata 重试兜底,保留
}
if (map.isStyleLoaded()) {
  tryFirstPaint()                 // style 已就绪(常见:内联 style 同步解析完)
} else {
  map.on('styledata', tryFirstPaint)      // 就绪事件路径
  setTimeout(tryFirstPaint, 800)          // 双保险:事件被吞时强制尝试,
                                          // addSource 若因未就绪抛错,走 paintTerritories 内部重试
}
```
- 保留年份变化的重绘路径并确认它不经过任何 isStyleLoaded 门禁
