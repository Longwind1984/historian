# 任务：后端 pytest 测试套件（T1.1）

## 目标
为 FastAPI 后端建立可作为质量闸门的 pytest 套件：任何人改坏 API 合同或索引逻辑，`pytest -q` 必须变红。

## 覆盖要求
1. **API 合同测试**（用 fastapi TestClient，真实加载 `data/` 与 `schema/`，不 mock 数据）：
   - `/api/meta/stats`：实体总数 >7000、按类型计数字段齐全
   - `/api/meta/schema`：包含 Person/Polity/Event/Battle/Faction/Place/Title 类型
   - `/api/entities?type=Person&...` 列表 + `/api/entities/{id}`（取一个已知 id 如 `p_li_bai`）+ 404 分支
   - `/api/entities/{id}/neighbors?depth=1`：结构含 root/depth/nodes
   - `/api/graph/shortest?from=p_li_bai&to=p_zhuxi&max_depth=6`：返回路径且跳数 ≥1
   - `/api/graph/contemporaries?person=p_li_bai&year=750`
   - `/api/territories?year=750`：FeatureCollection 且 features 数 >800；`year=-218`（秦）非空
   - `/api/timeline?from=600&to=900`
   - `/api/links/scan/{id}`、`/api/links/backlinks/{id}`、`/api/links/count/{id}`、`/api/links/search?q=李白`、`/api/links/global?limit=50&min_links=2`（node_count ≤50）
2. **索引单元测试**（`backend/app/core/data.py`）：
   - EntityIndex：by_id 命中/未命中、by_type 计数、persons_by_year 二分查找边界（含 BC 负数年份）
   - RelationIndex：邻接对称性、BFS shortest_path 自反(from==to)与不可达分支
3. **回归钉子**：`prefer_seed=true` 行为——750 年在世人物列表中种子人物（如李白）排前（对应历史 bug"此刻在世 0 人"）。

## 工程要求
- 测试放 `backend/tests/`，按 `test_api_*.py` / `test_index_*.py` 组织；共享 fixture 放 `conftest.py`（TestClient + 一次性索引构建，session 级复用，避免每个测试重建 7000 实体索引导致套件超慢）
- 数据相关断言写**下界**（如 >7000）不写精确值，避免数据增长打碎测试
- 需要 pytest 依赖：将 `pytest` 与 `httpx`（TestClient 依赖）加入 `backend/requirements.txt` 的开发段（用注释分隔 `# dev/test`）——这是本任务唯一允许的依赖变更
- 现有 `backend/tests/test_smoke.py` 如与新结构重复可整合进新套件（保留其断言语义）

## 边界（硬约束）
- 只允许修改：`backend/tests/**`、`backend/requirements.txt`；**不得改 `backend/app/**` 任何业务代码**——若测试暴露出真 bug，不修，写进报告的"遗留问题"
- 不执行 git commit / push
- 不降低断言强度来凑绿
