# 任务：Playwright E2E 冒烟 + P0 回归用例（T1.3）

## 目标
两条主路径的端到端冒烟测试，外加锁死两个已修 P0 的回归用例。任何人改坏主路径或让 P0 复发，`npm run test:e2e` 必须变红。

## 前置环境（已就绪，直接用）
- worktree 前端 dev server 已跑在 `http://127.0.0.1:5174`（vite 代理 /api → 127.0.0.1:8002 的 worktree 后端）
- 若 5174 不可达：报告并停止，**不要**自己起新服务、不要改端口

## 用例
**A. 时间柱主路径**（`e2e/timeline.spec.js`）
1. 打开 `/#year=750` → 标题含"唐"或"天寶"，「此刻在世」计数 >0
2. 在世人物列表点击「李白」→ 详情面板出现"李白"与生卒年
3. 搜索框输入"苏轼"→ 下拉/结果出现苏轼 → 点击 → 详情切换为苏轼
4. **P0b 回归（疆域）**：`/#year=750` 下，等待 ≤10s，断言疆域图例不显示「无疆域数据」，且 MapLibre 画布上 territory-fill 图层存在（可通过页面内 `window` 暴露的 map 实例或图例 DOM 判断——图例应显示至少 1 个政权条目或降级文案"疆域 N 块"；两种断言选可稳定实现的）

**B. 谱系星图主路径**（`e2e/graph.spec.js`）
1. 打开 `/#year=750&route=graph` → 头部出现"谱系星图"
2. **P0a 回归（布局）**：`.graph-canvas` 的 boundingBox 高度 ≥300px 且宽度 ≥600px；canvas 元素存在
3. 切「全局」模式 → 截断警告条出现（含"只渲染前"字样）且其 boundingBox 不与顶部工具条重叠（y 坐标大于工具条底边）
4. 「路径」模式：起点填 `p_caocao`、终点填 `p_yuefei`（若 UI 是实体名输入则用"曹操""岳飞"），执行查询 → 出现路径结果（步数 ≥1）——若路径 UI 需要特定交互（如从详情页发起），按实际 UI 调整用例并在报告说明

## 工程要求
- `frontend/package.json`：加 devDependency `@playwright/test`（本任务唯一允许的依赖变更），script `"test:e2e": "playwright test"`
- `frontend/playwright.config.js`：baseURL `http://127.0.0.1:5174`，**用系统 Chrome**：`projects: [{ name: 'chrome', use: { channel: 'chrome' } }]`（本机已装 Chrome，实测可用，勿下载 chromium 二进制）；不配置 webServer 自动启动，注释说明手动起服务的命令
- `@playwright/test` 已安装在 frontend/node_modules（package.json 已含），无需再装
- 提示：DEV 下页面暴露了 `window.__hkbMap`（MapLibre 实例），疆域断言可用 `page.waitForFunction(() => window.__hkbMap?.getLayer('territory-fill'))`；注意地图可能自动 flyTo 到选中人物出生地（如李白→碎叶城，中亚），queryRenderedFeatures 前先 `jumpTo({center:[109,33], zoom:3.8})` 并等 idle
- 等待策略：用 Playwright 自带的 auto-wait 与 `expect(...).toBeVisible()`；禁止裸 `waitForTimeout` 超过 2 处
- 选择器优先用文本/role，避免依赖易变的 class 名（`.graph-canvas` 这类结构断言除外）
