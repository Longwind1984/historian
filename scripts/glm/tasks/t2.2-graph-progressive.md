## Claude 探查确认（勿重复排查，按此实现）

### 关键事实（已读源码确认）
1. **Dynasty 字段是 `founded`/`ended`（{year,month}），不是任务书写的 `since/until`**；Person 无 `dynasty` 字段，只有 `born`/`died`（{year,month}）。归属算法：取实体 `born.year`（缺失则 fallback `died.year`）落在某朝代 `[founded.year, ended.year]` 区间；无年份或不在任何朝代区间 → `__unclassified`。
2. **数据里只有 8 个 Dynasty 实体**：sui/tang/song/liao/jin_jurchen/yuan/ming/qing（约 581–1912）。秦汉魏晋南北朝等人物无对应朝代 → 归「未分类」。未分类规模会很大，属正常数据现象，**报告如实给出数字即可**，不要为此加朝代数据。
3. T2.3 缓存就绪：`links.py` 里 `_ensure_graph()` 返回进程内单例 `_GRAPH`（`.out_ids` 出链 id 列表 / `.in_counts_occ` 反向计数），`_INDEX._entities_by_id` 有全部实体。新端点**必须复用**，禁止重新全量扫描文本。签名失效走 `_data_sig()`。
4. 现有 `/api/links/global` 已复用缓存（参考其写法）；新端点挂同一 `router`（前缀 `/api/links`）。
5. 前端入口：`GraphPanel.vue::loadGlobalGraph()` 当前调 `getGlobalGraph(120, 2)` 渲染经典全局；工具条在 `.panel-toolbar`；cytoscape 实例 `cy`、布局在 `runLayout()`，现动画 400ms。E2E B3 点 `.panel-toolbar button`（文本「全局」）后断言 `.overflow-banner` 含「只渲染前」。
6. 实体类型分布：Person 5311 / Place 1452 / Event 122 / Polity 55 / Battle 34 / Faction 28 / Dynasty 8。

### 后端契约（`backend/app/api/links.py`）
- 加模块级 `_dynasty_index`：`entity_id -> dynasty_id`（未分类 = `"__unclassified"`）。从 `_INDEX._entities_by_id` 取 `type=="Dynasty"` 的 `founded.year`/`ended.year`（缺则跳过该朝代）；对每个实体按上方规则归属。按 `_data_sig()` 缓存，签名失效重建（仿 `_ensure_graph`）。仅 8 朝代，线性匹配 O(N) 足够。
- `GET /api/links/global_by_dynasty`（level 1）：
  - 复用 `_ensure_graph()`；只统计 out+in >= 1 的实体（「双链实体」）。
  - 返回：
    ```json
    {
      "level": 1,
      "total_entities": <有链实体总数>,
      "total_links": <全部出链总数>,
      "dynasties": [{"id":"d_tang","name":"唐","entity_count":<int>,"link_count":<int>},
                    {"id":"__unclassified","name":"未分类","entity_count":<int>,"link_count":<int>}],
      "edges": [{"from":"d_tang","to":"d_song","count":<int>}]
    }
    ```
  - `entity_count` = 该朝代内有链实体数；`link_count` = 该朝代实体出链总数（sum len(out_ids)）。
  - `edges`：对每个 src 实体的 out_ids，目标实体朝代 Dt ≠ src 朝代 Ds 时，给无向边 `(min(Ds,Dt), max(Ds,Dt))` 计数 +1；from/to 用字典序稳定。仅含有链实体的朝代出现。
  - `__unclassified` 作为一个节点参与（name="未分类"）。节点总数 = 朝代数 +1 ≤ 9，满足 ≤20。
- `GET /api/links/global_by_dynasty/{dynasty_id}?limit=40&offset=0`（level 2）：
  - 返回：
    ```json
    {
      "level": 2,
      "dynasty_id": "...", "dynasty_name": "...",
      "total": <该朝代有链实体总数>,
      "other_count": <total - 已返回数>,
      "entities": [{"id","name","type","image","out","in"}],
      "edges": [{"from":"...","to":"...","type":"wiki_link"}]
    }
    ```
  - `entities` 按 out+in 降序取 `[offset, offset+limit)`；`edges` = 返回实体间的诱导子图出链（from/to 都在返回集合内）。
  - `dynasty_id` 也支持 `__unclassified`。
- `test_api_links.py` 加 1 条 `test_links_global_by_dynasty`：断言 level-1 status 200、有 `dynasties`/`edges`、`dynasties` 含 `id=="__unclassified"`、`len(dynasties) <= 20`、每个 dynasty 有 `entity_count>=0` 且 `link_count>=0`。
