# 任务：人物身份/重要性数据地基（T4.0）

为 M4 的「身份筛选」（T4.6）与 M5 内容重扫打地基：给 Person 加身份与重要性字段、注册枚举、给核心人物打样板标签、后端支持按此过滤。**本任务只做样板（手工种子人物 ~120 个），不碰 CBDB 4892 人**（那是 M5 批量活）。

## A. schema/person.yaml 扩展
新增两字段（读现有 person.yaml 字段风格后追加，保持缩进一致）：
- `roles`：array of enum，可多选。枚举 12 项（label 用中文）：
  `emperor 帝王` / `imperial_kin 宗室` / `consort 后妃` / `外戚 consort_kin` / `general 将领` / `civil_official 文臣` / `scholar 学者` / `literatus 文人` / `eunuch 宦官` / `rebel_leader 起义领袖` / `clergy 僧道` / `recluse 隐逸`
  （enum 值用英文 key，label 中文；照 schema 里既有 enum 字段的写法。若既有 enum 只存中文值，则统一用中文值，读代码定）
- `importance`：enum 或 int，取值 `1`(核心)/`2`(重要)/`3`(一般)，label：核心/重要/一般

## B. 样板标注（data/entities/persons/，仅改手工种子人物，不新增文件）
- 先 `grep -L "^id: p_cbdb_" data/entities/persons/*.yaml | head` 或按 id 前缀区分：**只标非 p_cbdb_ 的种子人物**（约 419 个中挑 ~120 个知名者）
- 每个标注 `roles`（可多个，如曹操=[general, emperor, literatus]；李白=[literatus]；王安石=[civil_official, scholar, literatus]；诸葛亮=[civil_official, general]）+ `importance`
- **importance 判据**（写进你的报告，别随意）：
  - `1 核心`：教科书级、家喻户晓——大一统王朝开国君/著名帝王、李白杜甫苏轼、岳飞文天祥、诸葛亮、王安石、司马迁等（约 60-80 人）
  - `2 重要`：正史有传、专业者熟知（其余种子人物多属此档）
  - `3 一般`：本任务样板不用（留给 M5 CBDB 人物默认档）
- roles 是可从史实客观判定的，无需 sources；不确定的人物 roles 留空而非硬猜（宁缺毋滥）
- 至少覆盖每个朝代的代表人物，保证筛选 UI 开发时每个 role 都有样本
