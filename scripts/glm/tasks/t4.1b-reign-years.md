# 任务：帝王在位年数据 + 世系段改用在位年（T4.1b）

背景：T4.1 帝王世系段现用生卒年近似（数据无在位字段），与本项目史料准确立意相悖。给 emperor 补真实在位年，世系段改用它。

## A. schema/person.yaml
新增可选字段 `reign`（对象 `{start: year, end: year}`，或两个平级字段 `reign_start`/`reign_end`——看现有 born/died 的写法选一致形式）。label：在位。可选（非帝王无此字段）。

## B. 数据：给 45 个 emperor 补在位年
- `env DATA_DIR=$PWD/data SCHEMA_DIR=$PWD/schema` 起后端或直接 `grep -rl "emperor" data/entities/persons/` 找出带 `roles:` 含 emperor 的人物（约 45，与 /api/entities?role=emperor 一致）
- 逐个补 `reign`（在位起讫年，正史通说）：
  - **sources 必填**：每个补 reign 的实体，其 sources 数组要含依据（如"史记·秦始皇本纪"、"资治通鉴"、"旧唐书·玄宗纪"）；若原 sources 已有正史即可复用
  - 追尊、未实际在位者（如曹操追尊武帝但生前未称帝）：**不填 reign**，在实体加 `note` 说明"追尊,无实际在位"；宁缺毋滥
  - 割据/短命政权君主（五代十国）尽量补，拿不准的留空并在报告列出
  - 改朝换代之年按通说归属（如 618 唐高祖即位）
- **不新增/删除实体**，只在已有 emperor 实体上加字段

## C. 前端：世系段优先用在位年
`frontend/src/components/timeline/TimeColumn.vue`：帝王段的起讫，**有 reign 用 reign，无则回退生卒**（现逻辑）；hover 名牌显示"在位 X–Y"（用 reign）或"生卒 X–Y"（回退时），二者可辨。改动最小化，别动缩放/tick 逻辑。

## D. 校验器
`scripts/validate_data.py`：若有 reign，校验 reign.start ≤ reign.end 且落在 [born, died] 附近（reign.start ≥ born 合理；允许 reign.end 略超 died？不允许，死后不在位——reign.end ≤ died）。越界 = WARN（列清单，不算 ERROR，避免个别史源差异卡死）。

## 边界
- 允许改：schema/person.yaml、data/entities/persons/*.yaml（仅 emperor 补字段）、frontend/src/components/timeline/TimeColumn.vue、scripts/validate_data.py
- 不改后端 API（reign 字段随实体自动返回，无需改 entity_service——除非 fields 白名单裁掉了它，检查 TimeColumn 的 getEntities fields 是否需加 reign，需要就在前端那行 fields 加 'reign' 或对应字段名）
- 不加依赖；不 git commit/push；不改 WORKLOG.md；环境变量用 `env VAR=... cmd`
