# 任务：左右分栏拖拽调节（T4.2，Rick 点名）

Rick 反馈：时间柱页左右两栏比例无法丝滑调节。做一个通用可拖拽分隔条，先应用到时间柱页（时间柱｜此刻面板）。

## 现状（先读懂）
- `frontend/src/App.vue`：`<main class="app-body">` 内 `<TimeColumn/>` + `<MomentPanel/>`，布局由 App.vue 的 `<style>` 里 grid/flex 定义（先读确认是 grid-template-columns 还是 flex）
- 目标：两栏之间插一根拖拽手柄，实时改比例，丝滑（拖动跟手、不闪）

## 要求
1. 新建 `frontend/src/components/shared/SplitPane.vue`（通用，横向）：
   - slots：`left` / `right`；prop：`storageKey`（持久化键）、`min`（各侧最小 px，默认 280）、`default`（初始左侧占比，默认 0.5）
   - 中间 6px 手柄：hover 变色、`cursor: col-resize`、按下拖拽实时更新比例（用 pointer 事件 + rAF 或直接 CSS 变量驱动，跟手无延迟）
   - **双击手柄→复位** default 比例
   - 比例持久化到 localStorage[storageKey]；拖拽中给 body 加 `user-select:none` 防选中文字，松开移除
   - 触摸屏 pointer 事件兼容
2. App.vue 时间柱 body 用 SplitPane 包住 TimeColumn（left）+ MomentPanel（right），storageKey='split-timeline'；**不改 TimeColumn/MomentPanel 内部**，只调外层容器
3. 视觉：手柄用设计变量（常态 --line 细线，hover/active --accent），克制——不加多余文案（交互一试即知，符合全局文案纪律）
4. 响应式：窗口 resize 时按比例保持；比例 clamp 在 [min 换算的下限, 上限] 内避免某侧被压没
