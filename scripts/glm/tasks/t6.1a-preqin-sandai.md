# 任务：先秦通史扩展 · 三代（夏 / 商 / 西周）(T6.1a)

补通史最前端：夏、商、西周。**商及以前无精确编年，用模糊纪年（约前 N 世纪 / 约前 N 年），并在 `ext.disputed: true` 标注**；共和元年（前 841）起中国有精确纪年。**将经 Anthropic workflow 逐条对抗核查（史实 + 中性），编造年份/职务/事迹会被打回。**

## 硬约定（先读，违反即打回）
- **年份一律负整数**（BCE），格式 `born: {year: -1046}`；模糊年取断代工程/史记通说的近似整数，并在 bio 写"约"，`ext.disputed: true`。
- **禁止悬空引用**：任何 `founder/ended_by/birthplace/capital/succeeded_by/preceded_by/from/to` 指向的 id，必须是你本任务新建的、或已存在的实体。都城若需引用 Place，**先 Read 一个现有 `data/entities/places/*.yaml` 照其格式新建**最小 Place（id+type+name+sources），否则**省略 capital/birthplace 字段**（宁可省略也不悬空）。
- **每个实体 `sources` 必填**（见下"信息源"）。事件 `category` 用新 14 类枚举（见 schema/event.yaml 注释）。
- roles 用枚举：emperor/imperial_kin/consort/consort_kin/general/civil_official/scholar/literatus/eunuch/rebel_leader/clergy/recluse。
- importance：1=家喻户晓，2=正史有传/专业者熟知，3=一般。
- 关系必带 `note`（一句话关联逻辑）+ 尽量带出处；亲属关系(father_of 等)可免 note。
- **不改代码/schema/已有实体**（只新建）；不 `git commit`；不改 WORKLOG.md；环境变量用 `env VAR=... cmd`。
